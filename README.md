# Many Searcher

O _Many Searcher_ é um buscador veloz e gratuito de informações do brasil, integrado com diversas APIs públicas e gratuitas o programa pode ser utilizado para agilizar buscas em lote, integrações em outros sistemas e composição de documentos

V1: O programa hoje contém duas funcionalidades, a busca unitária de CNPJ e a busca em lote de CNPJs via planilhas de excel.

O objetivo central do projeto é desenvolver uma ferramenta leve e ágil que futuramente deve buscar diversas informações importantes no âmbito brasileiro, como CEP, Cotação de Moeda, tabela Fipe, entre outros.
